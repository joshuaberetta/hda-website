Colour

Starting from the colours we already share.

The four member sites already overlap: three use a deep navy, two lead with red and two use teal. Each theme builds on those overlaps, so the alliance looks related to every member without copying any one of them.

Member colours, as observed

Sampled from the member website screenshots. Kobo values are taken from its site’s colors.scss. These are not official brand specifications, so each member should confirm them.

Where we overlap

These shared families become the backbone of every theme. Each theme tunes them slightly so no member’s exact colour is “the alliance colour”.

Theme palettes

Values are read live from each theme’s tokens.css. Contrast is against the theme’s page background, where 4.5:1 is needed for body text (AA) and 3:1 for large text and UI elements.

Colour values are drafts. Final values would be checked on print (CMYK) and in each member’s templates before sign-off.
